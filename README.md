# 📄 Resume Craft — Professional ATS-Friendly Resume Builder

> **Build, customize, and download ATS-optimized resumes in seconds.** Fully responsive across mobile, tablet, laptop, and desktop devices. Supports **PDF Download**, **Word (.docx) Export**, and **1-Page Clean Printing**.

---

## 🌟 Key Features

* 📜 **ATS-Friendly Templates**: Includes classic, modern, minimal, executive, and **Academic ATS (Divider Lines)** layouts.
* 📄 **1-Page Guaranteed Fit**: Automatically formats section spacing and line heights so freshers and experienced candidates can generate clean 1-page resumes.
* 💾 **Dual Export Options**:
  * **Download PDF**: Vector-scaled PDF export with custom applicant filename (`[Applicant_Name]_Resume.pdf`).
  * **Download Word (.docx)**: Fully editable Microsoft Word document export with MSOffice XML schemas.
  * **Clean Print**: Dedicated isolated iframe print engine (`window.print()`).
* 🎯 **Live Interactive Preview**: Real-time A4 preview paper updates instantly as you type into form fields.
* 🛡️ **Built-in ATS Score Checker**: Analyzes contact completeness, formatting structure, mandatory GitHub & LinkedIn URLs, and key resume sections (+100 max score).
* 🔒 **100% Privacy Focused**: Runs entirely client-side in the browser. Zero server data storage or external API keys needed.
* 📱 **Universal Cross-Device Responsive**: Optimized layout for mobile phones, tablets, laptops, and desktop computers.

---

## 🛠️ Technology Stack

* **Frontend Structure**: HTML5 (Semantic Structure)
* **Styling**: Vanilla CSS3 (Custom CSS Grid, Flexbox, Glassmorphism, CSS Variables, `@media` Responsive Breakpoints)
* **Logic**: Vanilla JavaScript (ES6+)
* **PDF Engine**: `html2pdf.js` (`html2canvas` + `jsPDF`)
* **Icons & Fonts**: FontAwesome 6, Google Fonts (Inter, Outfit, Playfair Display)

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Sarthak6262/Resume-Craft.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Resume-Craft
   ```
3. Open `index.html` in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

---

## 🌐 Deploying to GitHub Pages / Vercel

### Deploying on GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/Sarthak6262/Resume-Craft`
2. Click **Settings** > **Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Select `main` branch and `/ (root)` folder, then click **Save**.
5. Your live website will be available at: `https://sarthak6262.github.io/Resume-Craft/`

### Deploying on Vercel:
1. Go to [Vercel](https://vercel.com/) and log in.
2. Click **Add New Project** > Import `Resume-Craft` from GitHub.
3. Click **Deploy** (zero configuration needed).
